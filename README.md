# Octalve Vote

A secure, browser-based election platform in development for organizations.

**Status (20 October 2026):** The repository has been initialized, but the original GoVotin/Base44 application source has not yet been imported. No election or voting functionality is deployed from this repository.

Development work is staged through review branches and pull requests. Production voting must remain disabled until the code, authorization, ballot integrity, and browser-driven acceptance gates are independently verified.

See the review branch `review/octalve-vote-foundation-2026-10-20` for the first product foundation and documented release gates.
